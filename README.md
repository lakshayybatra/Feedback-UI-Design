# Feedback UI Design

This project is a simple user feedback interface built with HTML, CSS, and JavaScript. It lets users rate their customer support experience using a clean and interactive UI.

## Features

- 3-level feedback selection: Unhappy, Neutral, and Satisfied
- Smooth interactive rating selection
- Sent review button with a thank-you confirmation state
- Responsive and lightweight front-end design

## Project Structure

- `index.html` – page layout and feedback panel
- `style.css` – styling for the card layout and rating states
- `script.js` – interaction logic for selecting ratings and submitting feedback

## How to Run

1. Open `index.html` in a browser, or
2. Serve the project with a local static server such as:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
